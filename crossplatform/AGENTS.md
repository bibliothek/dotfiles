# Agent Instructions

## Output style

- Be terse. Answer in as few words as possible.
- No preamble, no summaries, no "great question" filler.
- Skip explanations unless I ask. Show code/commands directly.
- Don't suggest follow-ups or improvements unless I ask.

## Code

- Use minimal comments in generated code. Only comment non-obvious logic.

## Git

- Ask before pushing a branch, unless I explicitly told you to push.

## PRs

- PR descriptions and PR comments: as few words as possible. Very terse. No bullet-point essays.

## Reviews

- One-line summary of the change, then issues ordered by severity, most severe first.
- Only actual errors, not potential future problems.
- Always include filename and line number for each issue.
